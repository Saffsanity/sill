# `catalog-look`

**Checks:** whether a capture may be built from the catalog's last look at the windows and displays, or the catalog looks again first (2026-10-28: Sill.app 36.5 hours with no device, its last look's display 21 gone, the dock's displays back as 53 and 52, the Desktop built on 21's SCDisplay and refused by ScreenCaptureKit, "The stream is nil", the screen black): the display first, at any age (gone, asleep, none in the look while macOS has one), then no look, then a look older than two poll intervals; a look the poll keeps fresh never looked at again; an empty list of displays judged by the age alone; the poll interval followed; the Desktop's line ("display 21 → 53 …") and its one more try's, which starts as the old failure line did; the age's words; then 20,000 random looks against the rule's six properties
