# `connection-list`

**Checks:** the connect screen's list vs. tiles style (tiles by default since 2026-10-27, `defaultStyle`; a stored choice always kept: the list, tiles, nothing stored, a value no build writes, what the switch stores read back four times over); when a session's end keeps a picture for a tile (`takesPreview`: only with tiles, from a window in front, for a saved Mac, every combination); the saved Mac a row stands for (`tileMac`: one Mac listed as Wired, Wi-Fi by its name alone and Remote sharing its one picture, two Macs each their own, a row of no saved Mac the placeholder, the tag before a name, every row of one Mac under its group); what a launch or a change of style does (`previewPlan`: tiles → list → tiles, the pictures hidden and back, no file deleted by a style, only those of Macs no longer saved, a removed or forgotten Mac's not back); the picture, the stream's last keyframe decoded (`previewPixels`: 640 pixels wide at most, never wider than the video, its shape, the height rounded down; `looksBlack`: no colour channel above 24, the fourth byte and a row's padding never read, bad layouts black; `keepsDecodedPicture`: only while tiles are still on and the Mac still saved); Disconnect's fresh keyframe, asked of every Mac (`freshPicture` over every combination of its inputs, the recovery's 2 s spacing at its boundary); group names (cleaned, capped, a preset in any case the preset, Other never a group, a name in use in another case that group) and a superseded record's group carried to its successor; sections (one unnamed section when ungrouped, else the presets in their order, then other names as Finder sorts them, then Other, whatever order the Macs are listed in); preview JPEG filenames and stale-file pruning; tile column count

**Compiles:** `iOSClient/ConnectionList.swift` with `iOSClient/KeyframeRecovery.swift` (`swiftc`)
