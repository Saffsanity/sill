# `update-install`

**Checks:** Update Now, the one-click update, and Automatically update Sill (docs/one-click-update-plan.md §4 and §15): the trust and endpoints Sill.app uses, every refusal in its order and its words, what GitHub's release must say, the release's manifest, its signed date and its Ed25519 signature, a stop (keys made for the run and dropped; every compiled-in key usable, none of small order), the signer's in-person prompt with the whole SHA-256, the archive reader against zips built in the check (every hostile kind: traversal, absolute names, case duplicates, links out and through links, links at the signature's paths, setuid, encryption, zip64, local headers that disagree, shared bytes, bombs), the bundle's verdict, the state machine in both modes, Settings' and the menu's words naming both checks, the automatic update's rule (the switch, the cooling-off, the age and rollback limits, the stops, the attempts, the quiet moment, what it remembers); and T21's source rules: no Trust or Endpoints but the two constants, no UpdateInstaller but AppUpdater's, no default, environment or argument read by an updater file, the switch kept only in Sill's keychain group and set only from Settings

**Compiles:** `Sources/SillMenuBar/UpdateInstallPolicy.swift`, `UpdateManifest.swift`, `UpdateArchive.swift`, `UpdateAutoPolicy.swift` and `UpdatePolicy.swift` with `Sources/StreamProtocol` (`build.sh`; Foundation, CryptoKit, Compression), and the app's and the other targets' sources read as text
