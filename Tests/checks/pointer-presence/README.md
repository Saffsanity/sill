# `pointer-presence`

**Checks:** what the device's pointer sprite shows, row by row of the plan's table (the Mac's, the portrait trackpad's, the Pencil's, both flips), the portrait key row keeping what shows, a new frame re-centring only this device's own pointer while it shows, a report's freshness, the network queue's feed (the anchor, its re-seeds, a hand-over's carry-over and restatements), the portrait pad's cursor and its re-seed mid-stroke or under a resting finger; `TouchMode` (#178: Direct Touch or Trackpad, what `Sill.touchMode` holds and `stored` reads, `showsPointer` and the sprite it gives in each layout, who takes what lands on the picture in Trackpad mode (`taker`: a finger the trackpad, the Pencil, a connected trackpad's click, hover and scroll and a pinch the picture), and the Settings panel's words on an iPad and an iPhone)

**Compiles:** `iOSClient/PointerPresence.swift`
