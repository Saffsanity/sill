# `settings-window`

**Checks:** how tall Sill's Settings window may be on a screen and where it goes when Sill changes its size (issue #59, docs/settings-window-plan.md): a 14-inch at its default, larger-text and More Space scalings with and without the Dock (which pane fits which), an external 4K display at two scalings, screens above and beside with their own origins, a window partly off the screen above and below, never moved sideways or resized, Sill's virtual display never the screen, the TEST ONLY height; then 20,000 seeded random screens, chromes and frames against the rules' properties

**Compiles:** `Sources/SillMenuBar/SettingsWindowFit.swift`
