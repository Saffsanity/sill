# `file-store`

**Checks:** where files from devices land on the Mac (`FileStore`, docs/files-plan.md §7.1, §7.3 and §11), on a scratch folder of its own under `.build/checks/file-store`, never `~/Downloads`: the destination made with its parent (0755) and its hidden staging folder `.Sill Incoming` (0700) inside it; a staging file named by Sill, never by the sender, created new (0600) and never through a link; parts written and hashed, nothing under the file's name until it is whole; a file kept under its cleaned name, byte for byte, 0644, quarantined and not yet approved (LaunchServices reads Sill as its agent and an ordinary download as its type), Where from the device's cleaned name "through Sill"; the same name again numbered, a link to nothing at the name skipped and left as it was (`exists` sees it: lstat), the move into place on its own (`place`: a name taken after all tries the next number and never replaces, a full volume `noRoom`, another error the file's failure, every name taken giving up after 64 tries), a name that differs only in case numbered on a volume that ignores case, a 0-byte file; a wrong hash and a short file refused `damaged` with nothing kept and nothing left, no write after it is over, a second open of one staging file refused, discard; leftovers deleted and the destination's own files untouched; a destination or staging folder that is a link refused with nothing written through it; a folder chosen in Settings (taken when it is a writable folder; refused, with Settings' words, when it is a link, a file, gone or not writable); the free space; errno's meaning (a full volume or quota `noRoom`, anything else `cantSave`) and each failure's reason. Each file it keeps adds a quarantine event to this user's LaunchServices record, as any download does.

**Compiles:** `Sources/SillHost/FileStore.swift` with `Sources/StreamProtocol` (`module.txt`, `-package-name sill`)
