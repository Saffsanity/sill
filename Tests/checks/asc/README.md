# `asc`

**Checks:** the nightly's TestFlight tool: the token's header, claims and lifetime, never printed; groups; build-state; the wait for processing; What to Test (a build that has its own, in any language, keeps it unless `distribute --replace-whats-new`: the night of 2026-11-09 replaced 0.6.1 (1304)'s; `whats-new` always replaces; cut at 4,000); the internal groups, automatic distribution; the public beta's two locks and Beta App Review; retries, pages, redirects, another API host, usage

**Compiles:** `Scripts/asc.swift` whole (a script: no `main.swift`), run against `standin.py`, a stand-in App Store Connect on 127.0.0.1 that verifies every token's ES256 signature with openssl; throwaway P-256 keys made for each run; every run of asc under `sandbox-exec` with only loopback allowed, which the check tries first (a connection elsewhere refused)
