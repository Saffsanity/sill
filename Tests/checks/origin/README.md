# `origin`

**Checks:** which door a connection may use, by source address and interface; at the remote door a connection from this Mac itself, loopback or one of its own addresses, is a relay on it (issue #326: a userspace VPN node, a tunnel, a proxy), admitted there whatever the internet switch and never named at home; the last cases read this Mac's own interfaces (read-only)

**Compiles:** `Sources/SillHost/OriginPolicy.swift`, `InterfaceSnapshot.swift`
