# `stage-release`

**Checks:** when Sill's display for a picked window (the stage, Virtual Display) may be removed after the window was sent home through Accessibility (Noah's test of PR #355, 2026-11-12: Google Chrome, filling the Dell to the left of the main display, came back filling the main display, the display removed in the same millisecond as a move Chrome had not committed yet): a window listed at its home, kept elsewhere off the display, closed, or touching the display only by an edge has left it, one still on it or half on it has not, a home that itself reaches over the display is home all the same; the 1 s deadline and its 10 ms reads; the look after the removal (stay, put back once, gone; a window kept elsewhere stays there, never put back to a home on no display; 2 pt tolerance on every edge); a model of a window server and an app that commits the move late (every 5 ms from 0 to 2,000 ms, and never) through the order before (the display removed at once: every window not yet committed lost to the main display) and the new one (every window home; removed within 20 ms of a commit up to 1 s, never put back then; past it removed at 1 s and put back once); the wiring, read as text: select's Desktop or nothing, Virtual Display turned off and a stream that did not start wait, Quit and a shutdown mid-switch remove at once, a pick of another window keeps the display, `releaseWindow` notes the display the window left

**Compiles:** `Sources/SillHost/StageRelease.swift` (it reads `Sources/SillHost/VirtualStage.swift` and `Sources/SillHost/StreamCoordinator.swift` as text)
