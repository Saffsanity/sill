# `ask-limits`

**Checks:** the limits on a device's asks to pair at home: 10 minutes of quiet by key and by address, an IPv6 one by its /64 (after the Mac's Cancel or a stop, never an expiry or the device's own Cancel), 3 device-opened windows in any 10 minutes, the reason a proof turned away closed hears, the test override

**Compiles:** `Sources/SillHost/PairingWindow.swift`, `OriginPolicy.swift` and `DoorPolicy.swift` with `Sources/StreamProtocol` (`module.txt`)
