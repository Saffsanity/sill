# `camera-app`

**Checks:** Sill.app's side of Sill Camera (docs/camera-plan.md §6.5, §7, §11, step 8). `CameraExtensionPolicy`, one reducer: who may ask macOS (only Sill.app's own code from /Applications with Sill Camera inside and the install entitlement, which every other Sill.app says instead of asking; the bare binary's dry run asks nobody and says so); the switch (off asks nothing, on asks once, again only by Try Again or the next launch; an install, a start of the one installed, or an update of another build); macOS's answers (approval, with macOS 14's and 15's places and buttons; a replacement only inside an activation; completed, remembered as installed even when the approval came after the switch went off; after a restart; every failure code read as the section's state or a reason, a superseded request waiting for its own answer, another domain's code never taken for macOS's); removal (the switch off with it, nothing to remove read as removed, a refused removal still installed); System Settings' own switch; what the section shows whatever the request (Sill's feed reaching Sill Camera always shows it working, a switch off never does, camera access refused, turned off in System Settings, a refused Sill's reason); every state's line, attention, button and Remove Sill Camera…; the card's camera line; the dry run's script (read, sorted, refused at its edges). `CameraSinkPolicy`: the state Sill writes for what the receiver says (a pause paused, a name cleaned), the app Sill Camera's demand names (one, two, more, once each, an identifier's last part for an app gone, cleaned, at most 40 characters; nothing while nothing runs or for a demand Sill Camera could not have written), the sink's two frames (room: in; full: the newest waits in place of an older one; in when room comes unless a second old).
