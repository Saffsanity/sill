**Soft line breaks for multi-paragraph dictation and IME rewrites (2026-11-26, branch `feat/soft-newlines` from main at 22ab5a3).**
Addresses issue #437: voice dictation in keyboards such as WeType and Doubao replaces or streams spoken drafts with multi-paragraph text containing `"\n"`, which previously fired plain `Return` mid-utterance (submitting earlier paragraphs prematurely in chat and agent prompt boxes) and advanced `TextComposition.fence` (blocking follow-up cross-paragraph revisions).

- **The switch: `Soft Line Breaks`** (`iOSClient/SoftNewlines.swift`, pure; `Sill.softNewlines`, off unless turned on per the 2026-11-18 rule so spreadsheets and terminals keep plain `Return` by default; `HostSettingsPanel` under This iPad / This iPhone). `-Sill.softNewlines 1` turns it on for one run.
- **How it works.** `TextComposition` keeps the exact UTF-16 strings supplied by UIKit with no placeholder characters, so CRLF code-unit offsets, emoji surrogate pairs in marked text, already-fenced hard Returns (`"one\ntow"` with `fence == 4`), Korean cross-fence `retype`, and literal `U+2028` characters all remain intact:
  - Line breaks (`"\n"`, `"\r"`, `"\r\n"`) inside multi-character `insertText` / `unmarkText` commits and inside `replace` revisions emit `.softNewline` (`⇧Return`, `KeyChord.press(0x28, with: .shift)` under a `sendingTyped` guard so `StreamClient.onCaretMayMove` does not clear `composition.sent`) and leave `TextComposition.fence` open unless a `"\t"` also moved focus.
  - A standalone `insertText("\n")` waits briefly (`coalesceWindow`, 45 ms): if another edit arrives within `coalesceWindow` (as when a `UITextDocumentProxy` keyboard streams `insertText("line 1")`, `insertText("\n")`, `insertText("line 2")` token by token), the pending break is promoted to `.softNewline`; otherwise (including after fast two-thumb typing such as `"ok"` + Return) it settles as a plain `Return` and advances `fence`. Selection changes, responder teardown, and stale-generation refusals settle or preserve the pending Return cleanly.
- **Verified.** `Tests/checks/soft-newlines/run.sh` (31 assertions including 5,000 seeded random sessions), `Tests/checks/soft-newlines/run.sh --mutants` (17 of 17 mutants caught), `Tests/checks/text-composition/run.sh` (194 passed), `Tests/checks/repo-rules/run.sh` (11 of 11), iOS Simulator Debug build, and live multi-paragraph WeType voice dictation on an iPhone Duo (`iPhone19,4`, iOS 27.2.1) streaming from a MacBook Pro (macOS 27.2).
